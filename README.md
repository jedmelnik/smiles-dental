# Smiles Dental Care

Next.js rebuild of [smilesdental.com](https://smilesdental.com/) - Mountain View, CA family and cosmetic dentistry.

## Stack

- Next.js App Router + TypeScript + Tailwind CSS
- shadcn/ui primitives
- Deployed on Vercel

## Local development

```bash
npm install
npm run dev -- --port 43155
```

Open [http://127.0.0.1:43155](http://127.0.0.1:43155).
